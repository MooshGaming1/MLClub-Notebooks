# Meeting 5: Backpropagation From First Principles

## Overview

This meeting focuses on the mathematical foundations of backpropagation. Members study chain rule-based differentiation in computational graphs, perform manual gradient calculations, and compare those calculations against PyTorch autograd.

## Learning objectives

By the end of this meeting, members should be able to:

- Apply chain rule reasoning to multivariable functions.
- Interpret computational graphs for model calculations.
- Derive gradients for simple neural network components.
- Compute manual gradients for selected examples.
- Compare manual gradients with PyTorch autograd outputs.

## Topics covered

- Chain rule and multivariable differentiation.
- Computational graphs.
- Foundations of backpropagation.
- Manual gradient calculations.
- Manual vs. autograd gradient comparison.
