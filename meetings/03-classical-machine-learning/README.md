# Meeting 3: Classical Machine Learning

## Overview

This meeting introduces classical supervised learning techniques with an emphasis on model intuition and evaluation. Members study k-nearest neighbors, distance metrics, generalization, and overfitting while implementing a basic classifier.

## Learning objectives

By the end of this meeting, members should be able to:

- Explain the core idea of k-nearest neighbors.
- Compare common distance metrics conceptually.
- Distinguish training performance from generalization.
- Identify overfitting risks in simple models.
- Implement and evaluate a basic classifier.

## Topics covered

- K-nearest neighbors and distance metrics.
- Alternative learning algorithms (introductory overview).
- Model evaluation, generalization, and overfitting.
- Implementing a basic classifier.
