# Meeting 2: Gradient Descent & Logistic Regression

## Overview

This meeting develops optimization intuition by introducing derivatives, gradients, and gradient descent with learning rates. Members then apply these ideas to nonlinear regression with ReLU and binary classification with logistic regression and the sigmoid function.

## Learning objectives

By the end of this meeting, members should be able to:

- Interpret derivatives and gradients in optimization settings.
- Describe how learning rate affects gradient descent behavior.
- Implement gradient descent with NumPy.
- Explain logistic regression for binary classification.
- Use sigmoid outputs to interpret class probabilities.

## Topics covered

- Derivatives, gradients, and optimization.
- Gradient descent and learning rates.
- Nonlinear regression with ReLU.
- NumPy implementation of gradient descent.
- Logistic regression, sigmoid, and binary classification.
