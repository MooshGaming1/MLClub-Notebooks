# Meeting 4: Neural Networks & PyTorch

## Overview

This meeting introduces neural network fundamentals, including artificial neurons, activation functions, hidden layers, and multilayer perceptrons. It also introduces PyTorch and automatic differentiation through a simple training workflow.

## Learning objectives

By the end of this meeting, members should be able to:

- Describe basic neural network architecture components.
- Explain forward propagation in multilayer perceptrons.
- Use activation functions in hidden layers.
- Understand PyTorch tensors and autograd at an introductory level.
- Build and train a simple neural network model.

## Topics covered

- Neural network architectures and applications.
- Artificial neurons, activation functions, and hidden layers.
- Multilayer perceptrons and forward propagation.
- PyTorch and automatic differentiation.
- Building and training a simple neural network.
