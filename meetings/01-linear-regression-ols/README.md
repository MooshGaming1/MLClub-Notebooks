# Meeting 1: Introduction, Linear Regression & Ordinary Least Squares

## Overview

This meeting introduces the club and establishes the machine learning foundation for the semester. The session covers linear and multivariable regression, matrix-based formulations, mean squared error, and ordinary least squares solved with NumPy. It also introduces the limitations of linear models on nonlinear data.

## Learning objectives

By the end of this meeting, members should be able to:

- Explain the club's first-principles learning approach.
- Formulate linear regression using vectors and matrices.
- Define mean squared error and least squares objectives.
- Solve basic regression problems in NumPy.
- Identify situations where linear models are insufficient.

## Topics covered

- Introduction to the club and machine learning.
- Linear and multivariable regression.
- Matrix representation of regression.
- Mean squared error and least squares.
- Solving regression problems using NumPy.
- Limitations of linear models on nonlinear datasets.
